# Coffee Boss

A playable browser prototype inspired by the progression structure of early Facebook text RPGs such as Mob Wars, translated into a coffee shop game.

## Run

Open `index.html` in a modern browser. The game saves automatically to browser localStorage.

An internet connection is required for the Google Nunito font and Lucide icon CDN.

## Included systems

- Energy based shifts with cash, XP, mastery, and loot
- Drive and morale based rival challenges
- Persistent milestone and boss challenges
- Player levels and skill points
- Boss Points for resource refills
- Recurring location income with escalating purchase costs
- Inventory and loadout system with service and quality stats
- Crew recruitment and equipment capacity scaling
- Reserve account that protects cash from rival losses
- Collections, achievements, side challenges, districts, and unlock progression
- Offline regeneration and passive income
- Local autosave plus JSON export and import
